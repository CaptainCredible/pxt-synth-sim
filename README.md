Software synthesizer for the Micro:bit V2. 

## Sequencer, sound setup and presets (branch `sequencer-and-presets`)

The new blocks on this branch need changes to MakeCode core and to the NOTAM micro:bit simulator, which are not
in the hosted editors yet. Those changes are kept as patch files in [`core-patches/`](core-patches/README.md),
with instructions for running the editor locally.
